英語PDF を日本語PDF に変換

ローカルPDF翻訳

このパソコンの中だけで動いています。PDF をここにドラッグ&ドロップしてください (1 ファイルずつ処理します)。選んだだけでは始まりません。「翻訳を開始」を押すと始まります。

初回設定

    Gemini API キー

    翻訳に使います (無料)。Google AI Studio を開き、Google アカウントでログインして「Create API key」で作成し、コピーして下に貼り付けてください。キーはこのパソコンの自分のユーザー領域 (%APPDATA%\ReadableJP) にだけ保存され、画面やログには表示されません。

    構造補正 (任意)

    無くても簡易の構造解析で動きます。使う場合は、ご自身のCLIでログインしてください。

    プライバシーについて

    • Gemini 無料枠では、入力・出力が Google のモデル改善 (学習) に使われる可能性があります。未公開の論文や機密文書は送らないでください。
    • 構造補正を使うと、各段落の抜粋が選んだAIの提供元へ送られます。
