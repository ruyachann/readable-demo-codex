# Codex版の実装計画（2026-10-02）

## 要件と今回の完了条件

- Claude版とPDF抽出・Gemini翻訳・描画・検証を共有し、構造解析のCLIだけを交換する。
- Codex CLIは利用者自身のChatGPT認証を使う。API認証へ暗黙で切り替えない。
- PCブラウザーの操作画面、CLI、起動batでCodex版を利用できる。
- 配布ページでClaude版・Codex版を選び、別々のZIPをダウンロードできる。
- 配布ZIPの収録・秘密情報検査は `tools/build_dist.py` を唯一の正とする。
- ソースを複製して二系統に分ける方法ではなく、同じコードと版別設定・起動入口を配布する。
- 外部公開は行わず、検索除外とURL共有の条件を維持する。不自然な固定改行を増やさない。
- Claudeが読む進捗・担当範囲・検証結果・未確認事項を残す。

## 初期状態

Claude側の `docs/RESUME.md` では、Codex providerは後でCodexが実装することになっている。現在の `tests/test_codex.py` はCodexによるレビュー指摘の回帰テストであり、Codex CLI実装ではない。共通provider境界は `docs/STRUCTURE_PROVIDER.md` にある。

紹介・配布サイトは古い独立ビルダーで2026-10-01のソースを配布している。案1の着手を示す現在の更新は、開始時のメモでは確認できなかった。配布基盤の共通化と二版の選択を準備し、Claudeがサイト作業を開始したと確認できた場合はサイトの編集担当を引き渡す。

## 分担

- 主担当：共通provider登録・CLI・Web画面・統合・起動確認。
- GPT-6.1 Sol実装担当：Codex専用CLIアダプターと認証・構造化出力のテスト。
- GPT-6.1 Sol配布担当：共通ZIPビルダーの版別出力と検証。
- GPT-6.1 Sol進捗担当：Claudeとの共有メモ、作業状況の確認。
- GPT-6.1 Solレビュー担当：変更後の独立レビュー。

## 検証

実CLIのhelp／認証確認を可能な範囲で行い、処理・認証・不正応答・再開はモックテストで確認する。両配布ZIPを展開して起動入口とdummy翻訳を実行する。実AIによる文書翻訳の検証とモック検証は区別して記録する。Claude側の既存回帰テストも実施する。

## Claudeとの共有

入口：`docs/CODEX_CLAUDE_COORDINATION.md`。Codexの進捗：`docs/CODEX_PROGRESS.md`。アプリ共通部を同時編集する場合は変更範囲をメモに記録し、上書きしない。現在のClaude進捗メモや既存レビュー回答はCodexから書き換えない。
