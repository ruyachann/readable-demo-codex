# インストールガイド (Windows)

英語の PDF を日本語の PDF に変換するアプリです。あなたのパソコンの中だけで動きます。必要なのは、無料の Google アカウントで作る「Gemini API キー」だけです。

## 1. Python をインストールする (初回のみ)

1. <https://www.python.org/downloads/> から Python 3.11 以上をダウンロードして実行します。
2. 最初の画面で **「Add python.exe to PATH」にチェック**を入れてから Install を押します。

(すでに Python 3.11 以上が入っていれば不要です。)

## 2. ZIP を展開する

`ReadableJP-日付.zip` を右クリック → 「すべて展開」で、好きな場所 (例: デスクトップや ドキュメント) に展開します。**ZIP の中のまま実行しないでください。**

## 3. setup.bat を実行する (初回のみ)

展開したフォルダの `setup.bat` をダブルクリックします。必要なライブラリがフォルダ内の `.venv` に入ります (数分、インターネット接続が必要)。パソコンの他の場所は変更されません。「セットアップが完了しました」と出たら閉じます。

## 4. 翻訳アプリを起動する

`翻訳アプリ.bat` をダブルクリックします。ブラウザが開き、初回は設定画面が出ます。

1. **Gemini API キーを作る**: 画面のリンク (Google AI Studio) を開き、Google アカウントでログインして「Create API key」を押し、表示されたキーをコピーします (無料)。
2. キーを貼り付けて「保存」→「接続テスト」で確認します。キーはあなたのユーザー領域 (`%APPDATA%\ReadableJP`) にだけ保存され、他の人には見えず、画面にも表示されません。
3. プライバシーの注意を読み、チェックを入れて同意します。
4. 設定の項目がすべて緑のチェックになったら、PDF をドラッグ&ドロップして変換します。完了するとダウンロードできます。

使い終わったら、黒いウィンドウ (翻訳アプリ.bat) を閉じると終了します。

## 5. 選んだ版のCLIに契約ログインする

構成の整理に使います。**ご自身でログイン**してください (アプリは代行しません)。CLIが使えない場合は、理由と直し方を確認し、承認した場合だけ簡易解析で続けられます。

- Claude版: コマンドプロンプトで `claude` を起動して `/login`。
- Codex版: ターミナルで `codex login` を実行し、ChatGPTの契約アカウントでログインします。詳しくは [CODEX.md](CODEX.md)。共有ソースからは `翻訳アプリCodex.bat` で起動できます。
- 構成の整理は常にオンです (各段落の先頭・末尾の数十文字が、Claude版ではAnthropic、Codex版ではOpenAIに送られます)。使えない場合は、「翻訳を開始」や再試行を押したときに理由と直し方が表示され、同意すれば構成の整理なしで続けられます。

## プライバシー

- Gemini の無料枠では、送った内容 (論文の本文) と翻訳結果が Google の学習に使われる可能性があります。**未公開の論文や機密文書は変換しないでください。**
- アップロードした PDF と出力は、フォルダ内の `work\web_jobs` に置かれ、**最新の 1 件だけ**保持します (新しい翻訳を始めると前回の分は削除。アプリを終了して再起動した場合も削除)。必要なら先にダウンロードしてください。
- 翻訳の途中経過 (キャッシュ) は `work` に、最近使った 3 文書ぶんだけ残します。Gemini の日次上限で止まったとき、同じファイルで続きから再開するためです。

## アンインストール

1. このフォルダを削除します。
2. `%APPDATA%\ReadableJP` (エクスプローラーのアドレス欄に貼り付けて開けます) を削除します (保存した API キーと同意の記録です)。

レジストリや環境変数は変更していないので、これだけで完全に消えます。Python 本体は、不要ならそのまま「アプリの削除」から消せます。

## よくある質問

**「Python が見つかりません」と出る**: Python をインストールし、PATH のチェックを入れたか確認してください。入れ直したあと、新しいウィンドウで再実行します。

**setup.bat が失敗する**: インターネットに接続されているか、ZIP の中から実行していないか (先に展開) を確認してください。会社のパソコンで外部のダウンロードが制限されている場合は管理者に相談してください。

**「日本語フォント」が ✕ になる**: Windows の標準フォント (游明朝・游ゴシック・メイリオ) が見つからない場合です。`config.toml` の `[fonts]` に日本語フォントのファイルパスを書いてください。

**「日次上限」と表示される**: Gemini 無料枠の 1 日の上限です。翌日 16 時 (日本時間) 以降に同じファイルをもう一度入れると、続きから再開します。

**一部の段落が原文のままになった (警告)**: 結果欄の「この段落だけ再翻訳する」ボタンを押してください (ファイルを選び直す必要はありません)。

**キーを変えたい / 消したい**: 設定画面でもう一度貼り付けて保存するか、「削除」を押します。環境変数 `GEMINI_API_KEY` を設定している場合は、そちらが優先されます。

**スキャンした PDF は?**: 文字情報の無い PDF (画像だけ) は対応していません。

**他の人に見えますか?**: アプリは自分のパソコン (127.0.0.1) の中だけで動き、ネットワークの外から接続できません。
