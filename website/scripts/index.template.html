できること

論文の見取り図を、残したまま。

文章の理解と、図の確認を行き来しやすく。読むために必要な形を、できるだけ保ちます。

01 / LAYOUT

図や数式を残す

本文やキャプションを日本語に置き換え、図・表・数式は原文を保持。文字の長さに応じて配置やサイズを調整します。

02 / GLOSSARY

専門用語を揃える

文書ごとの用語集をつくり、訳語の表記を統一。glossary_fixed.toml に書いた固定訳は、どの論文でも優先します。

03 / YOUR PC

自分の環境で使う

PDF処理はPC上で実行。Gemini APIキーと、Claude CodeまたはCodex CLIの認証は、利用者自身のものを使います。

04 / TABLES

表の用語を本文と対応づける

図・表の本体と中の文字は英語のまま残します。本文の対応する用語は各ページの初出だけ「日本語 (English)」で併記し、色や下線は付けません。表や図への和訳の注釈は付けません (設定で付けることもできます)。

05 / SCANS & LINKS

スキャン本とリンクにも

OCR文字層のあるスキャンPDFに対応。原文のリンクとしおり (目次) も維持します。画像だけでOCR文字層の無いPDFや、スライドPDFは対象外です。

06 / RESUME

上限が来ても、続きから

Gemini無料枠の日次上限で止まっても、翻訳済みの部分は保存されます。翌日に同じPDFを渡せば続きから再開します。

両版の配布情報を開く

使い始め方

準備は初回だけ。あとは、PDFを選ぶ。

コードZIPを解凍してから進めてください。APIキーやログイン情報を、このサイトに入力する必要はありません。

  1. 01

    Pythonとライブラリを準備

    公式サイトからPython 3.11以上を導入。解凍したフォルダの setup.bat をダブルクリックします。手動で導入する場合は、フォルダ内で次のコマンドを実行します。

    python -m pip install -r requirements.txt

    Pythonや依存ライブラリはZIPに同梱していません。

  2. 02

    ご自身のAI利用環境を設定

    Google AI StudioでAPIキーを取得します。起動後の設定画面で登録できます。コマンドラインで使う場合は次のように設定し、ターミナルを開き直してください。

    setx GEMINI_API_KEY "あなたのAPIキー"

    初回の起動時は設定画面が開きます。Pythonなどの状態を確認し、Geminiキーの登録と接続テスト、外部AIへの送信についての同意を行います。キーはお使いのPCのご自身のユーザー領域にだけ保存されます。

    構造補正を使う場合、Claude版は Claude Code の /login、Codex版は Codex CLI の codex login で、ご自身の契約アカウントにログインします。利用量はご自身の契約に従います。

  3. 03

    PCで操作画面を開く

    翻訳アプリ.bat をダブルクリックすると、PCのブラウザに操作画面が開きます。PDFと出力形式を選び、「翻訳を開始」を押します。PDFを選んだだけでは始まりません。完成したPDFを画面からダウンロードし、一部の段落が失敗した場合は再添付せずに「この段落だけ再翻訳する」で再試行できます。

    翻訳アプリ.batPCのブラウザで操作PDFを選択日本語版PDF
    日英交互版PDF

    使い方は3通りです。(1) 翻訳アプリ.bat のブラウザ画面。(2) 翻訳する.bat にPDFをドラッグ&ドロップ (元のPDFと同じフォルダへ出力)。(3) コマンドラインで python -m readable 論文.pdf (--out で出力先、--mode ja|dual|both で出力形式を指定)。setup.bat を実行した場合は、フォルダ内の .venv が自動で使われます。

    処理時間はページ数・文量・APIの利用上限で変わります。

利用前に、外部AIへの送信について

PDF処理はPC上で動きますが、翻訳対象の文章などはGoogleへ、構造補正を使う場合は段落の抜粋などが、Claude版ではAnthropicへ、Codex版ではOpenAIへ送られます。無料サービスの条件では、Googleが入力・出力を製品改善等に利用する場合があります。機密情報や個人情報を含む文書は送信しないでください。

Claude版でAnthropicへ送るのは段落の抜粋 (先頭・末尾の数十文字など) です。翻訳の補助 (既定でオン) では、論文の題名・要旨、用語集、および翻訳が失敗した段落の原文も送ります。全文の校正のために全文を送ることはなく、--no-assist で補助だけ止められます。ClaudeのAPIキーやゲートウェイの設定 (ANTHROPIC_API_KEY など) を検出した場合は、API課金を避けるため構造補正をスキップし、契約ログインだけを使います。キー・ログインはすべて利用者ご自身のアカウントです。公式の利用条件を確認

よくある質問

使う前に、知っておきたいこと。

無料で使えますか？

Gemini APIの無料枠を利用する想定ですが、モデル・アカウントごとに適用条件や上限が変わります。Claude CodeまたはCodex CLIによる構造補正には、各サービスの対応する契約が必要です。利用量はご自身の契約に従います。Geminiの利用上限を確認

Claude CodeやCodexは必要ですか？

翻訳にはGemini API、構造補正には各版のCLIを使います。Claude版はClaude Code、Codex版はCodex CLIでご自身の契約アカウントにログインしてください。画面では構造補正を必ず試み、使えない場合は理由と直し方を表示します。構造補正なしでの続行を承認した場合だけ、簡易解析で翻訳します。両版の違いは構造補正の担当で、全文の日本語校正を行う機能ではありません。

スマートフォンでも翻訳できますか？

翻訳ツールはWindows PC向けです。PCにPythonや必要なライブラリを導入し、PCのブラウザ画面またはbatから実行します。スマートフォンでの翻訳操作は対象外です。

どんなPDFに対応していますか？

文字を選択・抽出できる英語PDFと、OCR文字層付きのスキャンPDFが対象です。画像だけのPDFに文字認識を新規実行する機能はありません。スライドPDFは論文向けの前提と合わず対象外です。表の本体は英語のまま残します (用語は本文に併記)。OCR誤りや複雑なレイアウトでは、訳文・重なり・原文の残りを確認してください。パスワード付きPDFは解除が必要です。

図や表の中の英語も翻訳されますか？

本文、見出し、キャプションなどを翻訳します。図中の文字、表本体、数式、所属、参考文献などは既定で原文のまま残します。図表内の英語に和訳の注釈は付けません (設定 annotations = true で、見えない注釈として付けられます)。

原文と同じ配置になりますか？

原文の配置をできるだけ保つように調整しますが、訳文の長さにより文字サイズや段落の位置が変わります。翻訳領域内の引用など、一部の内部リンクは失われる場合があります。すべてのPDFで同じ仕上がりは保証できません。翻訳内容と出力の見た目はご確認ください。

APIの上限や翻訳失敗はどう表示されますか？

終了コード7は日次上限です。上限解除後に同じPDFを実行すると、保存済みの翻訳から再開します。12は一部の段落が原文のまま残った状態で、PDFは出力されます。画面の「この段落だけ再翻訳する」ボタンで、再添付せずに再試行できます。8は設定や権限、9はAPIエラーや開発用の予算上限、11は日本語フォントの不足です。再試行時にも構造補正を使えるか確認します。

APIキーやPDFをこのサイトに送りますか？

このサイトは紹介とコード配布のためのページです。APIキーの入力やPDFのアップロードは行いません。翻訳操作画面で選んだPDFは、ご自身のPCで起動したローカル処理へ渡されます。ダウンロードしたツールから外部AIサービスへ送信される内容は、上記の利用条件をご確認ください。
